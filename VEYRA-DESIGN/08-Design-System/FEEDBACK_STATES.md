# VEYRA — Feedback States Visual System

## 1. Toast Notification Specs
- Background: `#0F172A` (Navy) with `#FFFFFF` text.
- Border Radius: `8px`, Shadow: `shadow-lg`.
- Auto-dismiss: `4000ms` with action button `[ Undo ]`.

---

## 2. Skeleton Loading Shimmers
- Base Color: `#E2E8F0` (`neutral-200`), Highlight: `#F1F5F9` (`neutral-100`).
- Animation: `animate-pulse` (1500ms cycle).
