# VEYRA — Responsive System Architecture

Aligned with Tailwind CSS breakpoints:

- `sm`: `640px` — Smartphone landscape & small tablets
- `md`: `768px` — Tablet portrait breakpoint (Sidebar transitions to drawer)
- `lg`: `1024px` — Desktop breakpoint (12-column grid active)
- `xl`: `1280px` — Large desktop workspace container
- `2xl`: `1536px` — Ultra-wide recruiter dashboard view
