# VEYRA — Interview Component System Architecture

## 1. Active Interview Question Card Component
- Large typography H2 question prompt (`24px / 32px`).
- Countdown timer badge (`12:42`) with subtle pulse animation when < 2 mins remain.

---

## 2. Audio Waveform Visualizer Component
- Active speech-to-text recording visualizer (5 animated vertical bar indicators driven by CSS keyframes or Web Audio API).

---

## 3. Interview Evaluation Report Card
- Category rating bars (Technical, Problem Solving, Communication, Role Alignment).
- Audio player scrubber with timestamped transcript triggers.
