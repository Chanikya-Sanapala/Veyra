# VEYRA — Accessibility Visual Specifications

Target Compliance: **WCAG 2.1 Level AA**.

- Primary Text (`#0F172A`) on Canvas (`#FFFFFF`): Contrast ratio **15.8:1** (Exceeds AA & AAA).
- Primary Blue Button (`#2563EB`) on White (`#FFFFFF`): Contrast ratio **4.6:1** (Passes AA).
- Focus Ring: `2px` solid `#2563EB` with `2px` white offset ring on focused controls.
- Non-color Status Badges: Verified strengths include `✓` checkmark icon; Skill gaps include `△` warning symbol.
