# VEYRA — Responsive High-Fidelity UI Adaptations

Defines desktop (`1440px`), tablet (`768px`), and mobile (`375px`) visual specs for the 3 flagship screens:

- **Desktop (1440px):** 256px Navy sidebar, 4-column KPI cards, 12-column applicant table, split-screen score breakdown drawers.
- **Tablet (768px):** Collapsed 64px icon sidebar, 2x2 grid KPI cards, full-width slide-over modals.
- **Mobile (375px):** Fixed 4-item bottom navigation bar, 1x1 stacked KPI cards, data tables transform to candidate touch cards, full-screen mobile dialogs.
