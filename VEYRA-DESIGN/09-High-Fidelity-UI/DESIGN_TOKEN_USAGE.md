# VEYRA — Design Token Usage Guidelines

Maps design tokens across color, typography, spacing, and elevation:

- Primary Buttons: `bg-primary-600 hover:bg-primary-700 text-white shadow-sm rounded-md`
- Cards: `bg-white border border-neutral-200 rounded-lg shadow-sm p-6`
- Page Headers: `text-3xl font-bold text-neutral-900 tracking-tight`
- Sub-headings: `text-lg font-semibold text-neutral-700`
- Tables: `w-full text-left text-sm text-neutral-800 tabular-nums`
