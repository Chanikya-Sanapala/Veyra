# VEYRA — Figma Implementation Guide for Flagship Screens

A step-by-step blueprint for building the 3 flagship screens in Figma:

## 1. Frame Setup & Grid Configuration
- Create Desktop Frame: `1440px x 1024px` (Name: `01 Desktop / Recruiter Overview`).
- Create Desktop Frame: `1440px x 2400px` (Name: `02 Desktop / Resume Match Analysis`).
- Create Desktop Frame: `1440px x 3200px` (Name: `03 Desktop / Public Homepage`).
- Apply 12-Column Grid: `Margin: 32px`, `Gutter: 24px`.

## 2. Auto Layout & Component Nesting
- Enable Auto Layout (`Shift + A`) on all cards, buttons, and tables.
- Use explicit component variants for Primary vs Secondary buttons, and Match Score vs Status badges.
