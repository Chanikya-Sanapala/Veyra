# VEYRA — Wireframe System States Architecture

This document outlines structural wireframe layouts for system states:

1. **Loading State:** Pulse shimmer placeholders matching card dimensions.
2. **Empty State:** Centered icon, informative title, explanatory body text, primary CTA button (`[ Post Job ]` or `[ Upload Resume ]`).
3. **Error State:** Non-intrusive red alert banner with error details and `[ Try Again ]` recovery CTA.
4. **AI Processing State:** Shimmer scanner card with step checklist: *1. Extracting Resume Text → 2. Computing Skill Overlap → 3. Generating Intelligence Summary*.
