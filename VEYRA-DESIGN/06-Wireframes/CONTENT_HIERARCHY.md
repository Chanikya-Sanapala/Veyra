# VEYRA — Content Hierarchy & CTA Rules

1. **Primary Information:** Page titles, Candidate names, Job titles, Primary Match Score (`94% Match`), Action Buttons (`[ Shortlist ]`, `[ Apply ]`).
2. **Secondary Information:** Sub-scores, Application statuses (`Interview`), Company names, Application dates, Skill tags.
3. **Supporting Information:** AI match explanations, disclaimer footnotes (*AI-generated evaluation to support human decision-making*), help text.
4. **CTA Positioning:** Primary action buttons are right-aligned in header action bars or sticky bottom bars.
