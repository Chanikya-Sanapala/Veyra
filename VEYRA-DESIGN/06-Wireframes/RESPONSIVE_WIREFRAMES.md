# VEYRA — Responsive Wireframe Adaptations

This document defines desktop, tablet, and mobile structural transformations across screens.

---

## Responsive Transformation Rules

| Desktop Layout (`≥1280px`) | Tablet Layout (`768px-1023px`) | Mobile Layout (`<768px`) |
| :--- | :--- | :--- |
| 256px Fixed Left Sidebar | Collapsed 64px Icon Sidebar | Bottom 4-Item Navigation Bar |
| 4-Column KPI Row | 2x2 Grid KPI Row | 1x1 Swipeable Stacked KPI Cards |
| 12-Column Applicant Data Table | 8-Column Horizontal Pan Table | Stacked Candidate Cards |
| Dual-Column Split Drawer | Full-width Slide-over Modal | Full-screen Slide-up Sheet |
| Multi-series Analytics Chart | Responsive Single-column Chart | Single-metric Pan Chart |
