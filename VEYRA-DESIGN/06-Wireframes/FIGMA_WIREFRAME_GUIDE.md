# VEYRA — Figma Wireframe Preparation Guide

A step-by-step guide for constructing wireframes in Figma:

## 1. Frame Setup & Breakpoints
- Create Desktop Frame: `1440px x 1024px` (Name: `Desktop / Recruiter Overview`).
- Create Mobile Frame: `375px x 812px` (Name: `Mobile / Candidate Overview`).

## 2. Layout Grids & Auto Layout
- Apply 12-Column Grid to Desktop Frame (`Margin: 32px`, `Gutter: 24px`).
- Enable Figma **Auto Layout** (`Shift + A`) on all component stacks. Set vertical gap to `24px` (`space-6`).

## 3. Recommended Figma Page Order
1. `01 — Recruiter Overview`
2. `02 — Candidate Overview`
3. `03 — Recruiter Jobs`
4. `04 — Job Details`
5. `05 — Candidate Profile`
6. `06 — Resume Match Analysis`
7. `07 — Candidate Intelligence`
8. `08 — AI Interview`
9. `09 — Candidate Jobs`
10. `10 — Applications`
11. `11 — Homepage`
